# 📊 Amazon Sales Dashboard — Power BI

## 📌 Project Overview

An interactive Amazon Sales Dashboard developed using Microsoft Power BI to analyze sales performance, customer behavior, product performance, and key business metrics.

The dashboard transforms raw sales data into meaningful insights through data cleaning, data modeling, DAX calculations, and interactive visualizations.

## 🎯 Business Objectives

- Analyze overall sales performance
- Track key sales KPIs
- Identify top-performing products and customers
- Analyze sales trends over time
- Understand customer purchasing behavior
- Compare performance across categories and regions
- Provide actionable business insights through interactive dashboards

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Data Modeling**
- **Data Visualization**

## 🔄 Project Workflow

1. Imported and prepared the sales data
2. Cleaned and transformed data using Power Query
3. Created relationships and developed the data model
4. Created calculated measures using DAX
5. Designed interactive visualizations
6. Developed the final sales dashboard
7. Analyzed the results and identified key business insights

- Interactive filters and slicers
